# Wind Forecast Monitor (UK day-ahead procurement)

A web app that shows a GB day-ahead power buyer the wind forecast available at decision time, and how accurate that forecast has been. It uses Elexon FUELHH and WINDFOR data for decisions made in January 2026.

**Status:** backend API, Decision view and Explorer view in place; the Accuracy report view is next. Hosting target: Vercel (deployment pending).
